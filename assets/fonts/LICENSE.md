# Font-Lizenz

`Fraunces-600.ttf` — statische Instanz (Weight 600) der Schriftfamilie
[Fraunces](https://fonts.google.com/specimen/Fraunces) von Undercase Type,
lizenziert unter der [SIL Open Font License 1.1](https://openfontlicense.org).

Wird ausschließlich zur Build-Zeit für die Open-Graph-Bildgenerierung
(`app/opengraph-image.tsx`) eingebettet; die Website selbst lädt Fraunces
über `next/font`.
